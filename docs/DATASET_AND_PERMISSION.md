# Dataset and permission note

Stage-4 was trained using multiple Bangladeshi food datasets together with PithaNet. PithaNet was used with direct permission from its author(s).

Raw PithaNet images, other raw food datasets, dataset archives, and private permission correspondence are intentionally not redistributed in this repository. This release contains only the trained LoRA adapter, class definitions, reproducibility metadata, and aggregate benchmark results.

## Training population

- Clean unique PithaNet training images: 4,152
- Previous Deshi Digest rehearsal samples: 2,720
- Total Stage-4 training samples: 6,872
- Held-out validation samples: 996

Anyone reproducing this work is responsible for obtaining appropriate access and complying with each dataset's terms and permissions. Do not add image manifests with absolute local or Kaggle paths to this public repository.
